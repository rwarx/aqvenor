## 1. Резюме

Проведён функциональный и визуальный аудит десктоп-приложения **Aqvenor** (Electron + .NET sidecar) по свежим исходникам из рабочей копии. Приложение собрано, запущено, проверено управление реальным вводом (мышь/клавиатура) и визуально, включая полный сквозной цикл работы с AI-провайдером по ключу пользователя.

**Общий вывод: приложение в рабочем состоянии.** Все ключевые пользовательские сценарии проходят: чат с живой моделью, выбор модели, обработка ошибок с Retry, MCP-серверы, генерация изображений, темы, переименование чатов, пер-проектная папка `.aqvenor`. Найдено **4 дефекта** (0 × P0/P1, 3 × P2, 1 × P3), ни один не блокирует основной сценарий.

## 6. Визуальное качество и удобство

**Сильное:** единая визуальная система (тёмная/светлая), аккуратные состояния hover/active/selected, информативный статус-бар, канвас с мини-картой/зумом/легендой, бар возможностей модели на hover — читаемый и правильный по содержанию (проверено против живого каталога: vision/tools проставлены верно).

**Замечания** (детали в BUGS.md):
- Док-панели не имеют минимальной ширины — панель может сжаться до нечитаемой (AQV-002).
- A11y-дерево переполняется узлами канваса — скринридер/AX-клиенты теряют остальной UI при открытом канвасе (AQV-001).
- Масса чатов «New chat» с флагом ручного переименования в истории пользователя — следствие дефекта AQV-003 (авто-тайтлы отключаются навсегда).

## 7. AI-интеграция

- Каталог живой: OpenRouter (436 моделей) + NVIDIA — загружаются, бейджи vision/tools/цены соответствуют.
- Ран идёт через `/api/agent/run` (агентский) — стриминг, статусы «Working/Idle», usage в сообщении.
- Ошибки провайдеров классифицируются и показываются человекочитаемо с кнопкой Retry.
- `/image`: модель для генерации выбирается автоматически из каталога (паттерн id), запрос уходит на выделенный эндпоинт; отказ провайдера по ключу отображается корректно.
- Токены хранятся в защищённом хранилище sidecar; в рендерер попадают только per-launch по мосту; в логах/скриншотах секретов нет.

## 8. Риски и порядок исправлений

1. **AQV-003** (P2) — авто-тайтлы навсегда отключаются у новых чатов: портит UX каждого нового чата. Фикс маленький (не отправлять «New chat» как титул при создании).
2. **AQV-002** (P2) — минимальная ширина док-панелей: один компонентный фикс.
3. **AQV-001** (P2) — переполнение a11y-дерева канвасом: `aria-hidden` на декоративных узлах / виртуализация списка узлов.
4. **AQV-005** (P3) — пикер модели у края экрана: проверить позиционирование вручную.
