## Aqvenor v0.3.0-alpha

**Still an alpha.** This release is about the workspace itself: a click no longer chops the window
into columns, the collapsed sidebar stops eating its own buttons, and the four defects the QA audit
found are closed. MCP servers, `/image` generation and the `.aqvenor` project folder ride along.

### What to do

- **If you were on `0.2.0-alpha`: take this one.** Your database, settings and DPAPI-encrypted keys
  stay where they were. Docked layouts are the one exception: the old layout was saved by the tiling
  dock, so it is dropped **once** and rebuilt as a single group. That is deliberate — restoring it
  would bring back the wall of two-pixel columns this release exists to remove.
- **If you have not installed it yet:** the [full description is here](https://github.com/rwarx/aqvenor#readme),
  and the one that matters is in *What you need* below.

### What you need

- Windows 10 version 1809 or later, or Windows 11
- The [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download) — the sidecar process the
  app starts is framework-dependent
- An API key from a provider configured in Settings — the app installs and runs without one; it
  simply cannot talk to a model

### A click opens a surface, it does not split the workspace

Every sidebar click used to dock the surface to the right of the active panel. Eight visits to the
sidebar meant eight side-by-side columns — in the audit the settings panel had been squeezed to
150px and its Install button to **2px**, so a click landed on nothing at all.

- A plain click now lays the surface **on top of the panel already in that group**. There is no tab
  strip; the sidebar is the switcher, and a surface you already have open is brought forward.
- Docking is something you ask for: the **open beside** button on a sidebar row (it appears on
  hover), `Alt+click`, the row menu, or dragging a row to an edge of the dock. Asking for a column
  when a panel is already stacked pulls that panel out into its own.
- Each panel carries a hover-close; closing the last one rebuilds the mode's default layout.
- **Panels have a floor** — `260 × 200`. A split that would leave less opens in place and says so,
  instead of producing an unreadable sliver.
- **The collapsed sidebar works again.** In the 48px rail the three work-mode buttons were `flex-1`
  inside an auto-height column, so flex shrank them from 26px to the 12px of their icons and they
  piled up on each other. They are fixed 28×28 squares now, with accessible names.

### The audit's four defects

- **Canvas nodes no longer flood the accessibility tree.** A 127-node graph put 127 `role="button"`
  cards into the tree, pushing the sidebar and toolbars past the 400-element cap — a screen reader
  lost the rest of the window. The cards are decorative for assistive tech; the same nodes are
  reachable in Files and Graph, and the canvas exposes one summary label with the counts.
- **The composer's model picker can no longer open off screen.** It was absolutely positioned inside
  a scrolled panel and was measured at `y ≈ −18858`. Popups (model picker, work-method menu) render
  through a portal, `position: fixed`, clamped into the viewport, and flip when the room above runs
  out.
- **New chats get auto-titles again.** The client sent the "New chat" placeholder as the title on
  `conversations.create`; the server reads any non-empty title as a hand rename and stops
  auto-titling that chat for good. Only a real, hand-typed title travels now.
- **Dock panels have a minimum size** — see above.

### Also in this release

- **MCP servers.** Built-in catalogues install in one click (Memory is one), remote HTTP endpoints
  can be added by URL, and the set survives a restart. Settings → MCP; the list mirrors into
  `<project>/.aqvenor/mcp.json`.
- **`/image`.** The command picks an image-capable model out of the live catalogue on its own and
  sends the prompt to the provider's image endpoint; a provider refusal is reported in plain words.
- **`.aqvenor` project folder.** Canvas, MCP set and a README are mirrored into the open workspace
  and read back when one is opened, so the spatial layout travels with the repository.
- **Export / import menu**, in the sidebar and the page header.
- **Editable sidebar** — the pencil turns the workspace rows into show/hide toggles; the choice is
  remembered per user.

### What is still rough

- **Weak models make weak agents.** On `meta/llama-3.2-11b` the agent calls tools correctly
  (`list_files`, `read_canvas`) but guesses paths and occasionally emits a malformed tool call; the
  chat reports it and offers Retry rather than pretending. Use a model that is good at tool calls.
- **Provider availability is on the provider.** NVIDIA's `z-ai/glm-5.3*` answers a geo-block (451)
  from some networks; OpenRouter keys without credit answer `402` or a policy denial. The app shows
  all of these verbatim and lets you retry.
- **Stop, system theme and window resizing** are still not covered by automated tests.
