## Aqvenor v0.3.3-alpha

Released on 9 November 2026.

This alpha adds editable scenarios, real task delegation and explicit CMD and
PowerShell tools. It also simplifies Settings and fixes interrupted answers and
ownership of active child conversations.

### Scenarios and subagents

- Seven tasks provide editable instructions, model selection, the current
  project and actual tool availability. Each scenario preserves its own brief.
- `delegate_task` creates a real child chat with the parent's captured model,
  workspace, mode and approval policy. Limits are three tasks per run and twelve
  model steps per child, with no recursive delegation.
- Progress and result links open the actual child chat. An active child remains
  viewable and links back to its controlling parent; sending, regeneration and
  deletion become available after parent cleanup. Stop cascades to children.
- Enable delegation in **Settings → Agent**. The chosen provider/model must
  support tool calls; task selection alone does not guarantee a model uses them.

### CMD, PowerShell and permissions

- `run_shell` starts system CMD or Windows PowerShell. Program and shell
  permissions are separate and off by default. In
  **Settings → Advanced → Permissions**, first allow running programs, then
  enable CMD/PowerShell. Each permission change uses native desktop confirmation.
- Every shell invocation requires approval showing the complete script.
  PowerShell accepts multiline scripts; CMD accepts a single command line.
- The starting directory resolves inside the selected project. Scripts run
  with the Windows user's rights and can access other files or network
  resources; the directory guard is not an OS sandbox. Output is capped, and
  timeout or cancellation terminates the process tree.
- Ordinary settings requests cannot enable program or shell execution.
  Privileged permission changes require a private credential held by the host.

### Reliability

- Responses cut short by an output-token limit keep partial text and explain
  how to continue. Truncated tool calls are discarded before approval or
  execution. Step and time limits also show unfinished tasks.
- Reserved child chats reject independent runs and message changes until
  cleanup. Failed cancellation retains ownership until a confirmed retry.
- Early Stop preserves new draft attachments and finishes empty assistant
  placeholders. Model-picker focus, narrow panels, long labels and slider
  accessibility have regression coverage.
- Provider diagnostics and project-file hydration recover consistently after
  backend connection errors while preserving unsaved content.

### Installation and validation

Use the attached x64 Windows installer, or check for updates from an installed
`0.3.2-alpha` build. The .NET runtime is included. The release includes
`alpha.yml`, `latest.yml`, the installer blockmap, SHA-256 checksums and its exact
source commit. Windows packages are currently unsigned.

Local verification passed 287 renderer tests and 1165 backend tests, with eight
opt-in provider tests disabled. Separate real OpenRouter AutoRouter checks
completed delegation and both shell types. Two pages generated by Aqvenor passed
56 and 67 Chromium checks after the agent corrected their form validation and
header compatibility.

Native Electron computer-use captures timed out. Those checks are not presented
as native UI acceptance; the recorded browser fixtures and real provider/process
checks have separate scope. The original WPF host has no dedicated output-limit
banner or matching scenario/subagent controls. Future Canvas ideas remain
documentation only.
