=== ПОЛИТИКА ИСПОЛЬЗОВАНИЯ И РАСКРЫТИЕ ===

1. Всё работает на вашем компьютере. Переписки (SQLite), ключи API (шифруются
   DPAPI), индекс и пространственный граф рабочего пространства остаются
   локально. Телеметрии, аналитики, crash-отчётов и аккаунтов нет, серверов
   проекта нет.

2. Эта программа может писать файлы и запускать программы. Агент работает
   только в указанной вами рабочей папке и запрашивает подтверждение перед
   каждым изменением, но это заявленное поведение, а не гарантия. Открывайте
   папку, которую вы готовы отдать ему на редактирование, держите git и
   резервные копии.

3. С машины уходит только то, что вы отправляете выбранному провайдеру
   моделей, и только по нажатию «Отправить» - по правилам этого провайдера.
   То же верно для git push/pull/fetch вашего собственного репозитория.

4. Выполнение команд, загрузка из сети и доступ к файлам вне проекта
   выключены по умолчанию, и каждый вызов включённой возможности сначала
   запрашивает подтверждение. Не включайте без необходимости.

5. Это программное обеспечение до релиза, без прямых или подразумеваемых
   гарантий. Используйте на свой риск.

6. Нажимая «Я согласен», вы принимаете условия выше. Полные документы -
   LICENSE, SECURITY.md и PRIVACY.md - в репозитории.
