=== 사용 정책 및 고지 사항 ===

1. 모든 것이 사용자의 컴퓨터에서 실행됩니다. 대화 기록(SQLite), API 키(DPAPI 암호화),
   워크스페이스 인덱스와 공간 그래프는 모두 로컬에 유지됩니다. 텔레메트리, 분석,
   크래시 리포트, 계정, 프로젝트 운영 서버는 전혀 없습니다.

2. 이 프로그램은 파일을 쓰고 프로그램을 실행할 수 있습니다. 에이전트는 사용자가 지정한
   워크스페이스 폴더 안에서만 동작하며 매 변경 전에 승인을 요청하지만, 이는 의도된
   동작에 대한 설명이지 보장이 아닙니다. 편집을 맡겨도 되는 폴더를 열고, git 커밋과
   백업을 유지하십시오.

3. 컴퓨터를 벗어나는 것은 사용자가 선택한 모델 제공자에게 보내는 것이며, Send를 누를
   때만, 그 제공자의 정책에 따릅니다. 자신의 저장소에 대한 git push/pull/fetch도
   마찬가지입니다.

4. 명령 실행, 네트워크 가져오기, 프로젝트 외부 파일 접근은 기본적으로 꺼져 있으며,
   켠 경우 그 호출마다 승인을 요청합니다. 필요 없으면 끄지 마십시오.

5. 정식 출시 전 소프트웨어이며 어떠한 명시적·묵시적 보증도 없습니다. 사용자 자신의
   책임 하에 사용하십시오.

6. "동의함"을 클릭하면 위 조건에 동의한 것으로 간주됩니다. 전체 문서(LICENSE,
   SECURITY.md, PRIVACY.md)는 저장소에 있습니다.
