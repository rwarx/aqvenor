=== USAGE POLICY AND DISCLOSURES ===

1. Everything runs on your machine. Conversations (SQLite), API keys
   (DPAPI-encrypted), the workspace index and the spatial graph stay local.
   There is no telemetry, no analytics, no crash reporting, no accounts, and
   no server operated by this project.

2. This program can write files and run programs. The agent works inside the
   workspace folder you nominate and asks before every change, but that is a
   description of the intended behaviour, not a guarantee. Open a folder you
   are willing to let it edit, keep your work committed, keep backups.

3. What leaves your machine is what you send to a model provider, and only
   when you press Send - under that provider's policy. The same applies when
   you run git push/pull/fetch on your own repository.

4. Command execution, network fetching and out-of-project file access are
   disabled by default, and every call of an enabled capability asks for your
   approval first. Keep them off unless the task requires them.

5. This is pre-release software with no express or implied warranty. Use it
   at your own risk.

   LICENSE, SECURITY.md and PRIVACY.md - are in the repository.
