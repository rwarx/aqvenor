=== POLITICA D'USO E AVVERTENZE ===

1. Tutto gira sulla tua macchina. Le conversazioni (SQLite), le chiavi API
   (cifrature DPAPI), l'indice dell'area di lavoro e il grafo spaziale restano
   in locale. Nessuna telemetria, nessuna analytics, nessun report di crash,
   nessun account, nessun server del progetto.

2. Questo programma puo scrivere file ed eseguire programmi. L'agente lavora
   solo nella cartella di lavoro che indichi e chiede conferma prima di ogni
   modifica; e un comportamento dichiarato, non una garanzia. Apri una cartella
   che sei disposto a consegnargli, tieni il lavoro committato e i backup
   aggiornati.

3. Lascia la macchina solo cio che invii al fornitore di modelli scelto, e solo
   quando premi Invia, secondo le regole di quel fornitore. Vale anche per
   git push/pull/fetch sul tuo stesso repository.

4. Esecuzione di comandi, richieste di rete e accesso a file fuori dal progetto
   sono disattivati per impostazione predefinita; ogni uso di una capacita
   attiva chiede prima la tua approvazione. Non attivarli se non serve.

5. Software in pre-rilascio, senza garanzie espresse o implicite. Usalo a tuo
   rischio.

6. Cliccando "Accetto" accetti i termini precedenti. I documenti completi -
   LICENSE, SECURITY.md e PRIVACY.md - sono nel repository.
